# UI/UX Design Direction

## 1. Arah Desain yang Direkomendasikan
- Karakter Visual: Modern, Clean, Professional, Trustworthy.
- Target Pengguna: Calon siswa, Orang tua, Alumni, Guru/Staf, Publik.

## 2. Design Principles
- Mobile-first approach (Layout dan animasi dioptimasi dari layar kecil).
- Konsistensi identitas visual antarsekolah (namun tetap customizable secara warna).
- Accessibility (kontras warna yang baik, ukuran target tap memadai).

## 3. Aturan Resolusi
- **Mobile Rules**: Maksimalisasi ruang layar, gunakan bottom navigation atau drawer jika perlu.
- **Desktop Rules**: Tampilkan menu terbuka (tanpa burger menu), grid layout.
